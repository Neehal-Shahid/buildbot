To run a manual sync, go to your WordPress Admin panel > WooCommerce > BuildBot and click Sync.

1
Download the BuildBot Plugin
Download and install this plugin on your WordPress website.
2
Install on WordPress
Go to WordPress Dashboard → Plugins → Add New → Upload Plugin
Select the downloaded .zip file → Click Install Now → Activate
3
Copy Your Secret Key
Paste this key in the BuildBot plugin settings on WordPress.
Click "Generate Key" to create your secret key

4
Connect from WordPress
In WordPress go to BuildBot in the left menu.
Enter your Store ID and Secret Key → Click Connect & Sync.
